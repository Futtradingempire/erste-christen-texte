# Korrekturen vorschlagen

Öffne das betreffende Kapitel in der [Textbibliothek](https://www.erste-christen.de/textbibliothek)
und klicke auf „Korrektur vorschlagen“. Gib eine eindeutige kurze Textstelle, deinen Ersatztext
und eine Begründung an. Prüfe die Vorschau vor dem Absenden. Anzeigenamen sind freiwillig;
bitte veröffentliche keine persönlichen Kontaktdaten. Die Vorschläge sind öffentlich.

Mit der Einreichung bestätigst du, dass dein Beitrag unter CC BY-NC-SA 4.0 veröffentlicht werden darf.
Übernimm keine geschützten fremden Übersetzungen ohne passende Erlaubnis.

Technisch enthält ein Vorschlag genau eine Datei `corrections/<preview-hash>.json` im Format
`public-library-correction-v1`. Die Website erzeugt IDs, Ausgangsversion und Prüfhash automatisch.
GitHub-Nutzer können einen solchen Vorschlag ebenfalls als Pull Request einreichen.
Die Dateien unter `texte/` werden aus ChurchFathers erzeugt und beim Abgleich überschrieben;
redaktionelle Textänderungen erfolgen deshalb über Korrekturvorschläge.

Die Redaktion prüft und führt den Vorschlag zusammen. Danach lädt sie im ChurchFathers-Backend
die identische Vorschau und übernimmt sie ausdrücklich. Veraltete Vorschläge werden nicht automatisch
auf neuere Texte angewendet. Frühere Fassungen bleiben nachvollziehbar. Ein Kommentar bestätigt
die Übernahme auf der Website; das Archiv folgt beim nächsten regelmäßigen Abgleich.
